# Bounded compressed-fragment inspection tests

This standalone host exercises the original zlib fragment adapter and strict DEFLATE structure walker. Its 49 synthetic fixture records (21 valid and 28 malformed) plus fifteen support groups require exactly **64** passing groups. Fixtures are copied beside the host; the default invocation needs no external inputs or game installation.

```text
dotnet run --project tools/OwnedReservoirInflationTests -c Release
dotnet build tools/OwnedReservoirInflationTests -c Release -p:InflationTargetFramework=netstandard2.1
```

The default target is net10.0. The netstandard2.1 target compiles only the three directly linked helpers as a library, with Program.cs removed. The host accepts either no arguments, using AppContext.BaseDirectory/Fixtures, or one explicit fixture-directory path. It has no actual-capture mode or platform drive mapping.

The integrated default host passes all 64 groups on Windows and WSL Linux with identical complete summaries and ordered case names. Both host and netstandard2.1 builds report zero warnings/errors. Normal ONI-project compilation succeeds with its two previously documented MSB3277 assembly-reference warnings. Separate actual Windows ONI Mono validation passes 57 private groups and recovers an independently observed ordinary save body after native save/reload. See [runtime evidence and limits](../../docs/owned-reservoir-bridge.md#bounded-compressed-fragment-inspection); Linux Unity remains unverified.

The first adapter's codec accepted an invalid distance/reference before any output history existed. That failure remains a required malformed regression. A second version added the original strict structural walker but its codec rejected a valid repeat18 spanning literal/length and distance alphabets. That valid stream remains a required positive control. The current adapter preserves the walker and uses System.IO.Compression.DeflateStream on the already structurally validated raw DEFLATE range. None of the controls, expected reasons or bounds is relaxed to hide either predecessor failure.

The synthetic corpus covers empty/stored/fixed/dynamic blocks, literal-only and single-distance alphabets, repeat codes, overlapping and cross-block references, complete malformed tree/reference controls and trailing/concatenated streams. Support groups retain truncation, checksum/header rejection, exact output caps, source/compressed bounds, actual decoder Read-call limits, structural block/symbol limits, immutable copy isolation and parallel-call checks. Every stream/plain fixture is authenticated against the original manifest's length and SHA256; no fixture is decoded or regenerated by test preparation.

The API accepts an immutable source image and an explicit caller-supplied compressed byte range. The strict walk proves final-block closure, reference history and the exact zlib trailer position before the platform decoder is created. The adapter bounds produced bytes and Read calls, requires actual decoder EOF and structural output agreement, and checks Adler-32. Decoder Stream.Position/read-ahead is never framing proof. The output limit bounds accepted data, not peak managed heap.

Success establishes bounded inspection of that supplied compressed fragment. It does not discover a whole save's section boundaries, validate native Sim data, use a native reader, authorize a native load, prove whole-file preflight, assign ownership, permit restoration/writing/quarantine or pass the first playable colony gate. These report denials are asserted by the host. This project contains only original synthetic data and source; it requires no captured saves, game/Unity assemblies, vendor codec or licensed fixture inputs.
